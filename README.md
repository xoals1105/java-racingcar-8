# 자동차 경주
***
## 기능 요구사항 체크리스트
### 입력/검증

- [ ] 자동차 이름은 쉼표(,) 로 구분하여 입력받는다.
- [x] 각 자동차 이름은 1~5자여야 한다.
- [x] 이름 토큰의 앞뒤 공백을 `trim` 처리한다.
- [x] 빈 토큰(예: `pobi,,jun`) 은 허용하지 않는다 → `IllegalArgumentException`.
- [x] 중복 이름을 허용하지 않는다 → `IllegalArgumentException`.
- [ ] 시도 횟수는 양의 정수만 입력받는다(0, 음수, 숫자 아님 → 예외).
- [ ] 입력 프롬프트 문구를 과제 예시와 동일하게 출력한다.

---

### 경주 규칙

- [x] 매 라운드 각 자동차에 대해 0~9 정수 난수 1개를 생성한다.
- [x] 난수 ≥ 4 이면 전진 ≤ 3 이면 정지한다.
- [x] 사용자 입력 시도 횟수 만큼 라운드를 반복한다.

---

### 출력 규칙

- [ ] `실행 결과` 헤더를 출력한다.
- [x] 각 라운드 종료 시 `이름 : ----` 형식으로 누적 결과를 줄바꿈하여 출력한다.
- [ ] 라운드별 출력 사이에 빈 줄을 넣는다(예시와 동일).
- [x] 모든 라운드 종료 후 최대 거리를 계산한다.
- [x] 최대 거리에 해당하는 자동차(들)를 우승자로 선정한다(복수 가능).
- [x] 우승자 출력 형식은 `최종 우승자 : a` 또는 `최종 우승자 : a, b` (쉼표+공백) 로 한다.

---

###  예외 / 종료 규칙

- [ ] 잘못된 입력이 들어오면 `IllegalArgumentException` 을 발생시키고 애플리케이션을 종료한다.
- [ ] `System.exit()` 사용 금지.

---

### 구현 제약

- [x] 난수는 `camp.nextstep.edu.missionutils.Randoms#pickNumberInRange(0, 9)` 를 사용한다.
- [ ] 입력은 `camp.nextstep.edu.missionutils.Console#readLine()` 을 사용한다.
- [x] 프로그램 시작점은 `Application.main()` 이어야 한다.
- [ ] `build.gradle` 변경 금지, 제공 외 외부 라이브러리 금지, 파일/패키지명 변경 금지(명시된 한도 내).
